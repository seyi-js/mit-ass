# Five-minute audiovisual PowerPoint outline

The brief requires a PowerPoint audiovisual presentation. This outline is a
preparation aid, not a completed presentation or recording. Final slides should
include verified deployment and testing results.

| Time      | Slide / demonstration                                                                     | Evidence                                                                    |
| --------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 0:00–0:35 | Problem and objectives: fragmented complaints and missing accountability.                 | University maintenance scenario.                                            |
| 0:35–1:10 | Architecture and roles: React, NestJS, PostgreSQL; student/staff, officer, administrator. | Database relationships diagram.                                             |
| 1:10–2:00 | Student workflow: registration, request submission, tracking.                             | Student dashboard and request-form screenshots.                             |
| 2:00–2:50 | Administrator and officer workflow: create officer, assign, start work, complete.         | Assignment and request-history screenshots.                                 |
| 2:50–3:30 | Advanced features and reports.                                                            | Session/RBAC explanation, search/filter/pagination, Swagger, report screen. |
| 3:30–4:15 | Testing: frontend, API, permissions, concurrent status changes, browser workflow.         | Actual test output and screenshots.                                         |
| 4:15–5:00 | Deployment, challenges, conclusion, repository link.                                      | Verified live URL and database health response.                             |

Record narration over the slides and include a short screen demonstration where
it makes the workflow clearer. Keep the total duration at five minutes.
